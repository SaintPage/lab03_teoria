# Laboratorio 3 - Teoria de la Computacion

## Autores

- 23661 - Angel Merida

## Descripcion

Tercer laboratorio del curso de Teoria de la Computacion. El repositorio incluye el codigo para el problema 1 del laboratorio: construccion del arbol sintactico de una expresion regular a partir del algoritmo de Shunting Yard.

## Ejecucion

Requisitos: Python 3 y matplotlib.

```
pip install matplotlib
python3 main.py
```

El programa lee expresiones.txt, procesa cada linea y guarda el arbol sintactico de cada expresion como un PNG en la carpeta salida.
